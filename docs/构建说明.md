# 构建说明

器件PH1P35MDG324，速度等级3；参考工具为Tang Dynasty 6.2.168116，仿真参考Vivado 2025.2，Python参考3.13.12。

软件：先安装Python 3.13，根目录运行安装环境.cmd，然后运行启动上位机.cmd。上位机采用PySide6 6.9.2、numpy 2.3.5。

硬件：设置TD_EXEC指向td_commands_prompt.exe，设置VIVADO_BIN指向Vivado的bin目录。运行 python scripts/build_all.py。脚本依次仿真、综合、布局、布线、双视图时序与独立检查，全部满足后生成位流；任何失败停止。不要使用图形界面的默认策略代替脚本所固定的布局、约束和检查。仿真结果与构建输出在build目录。需要本机有效工具授权，仓库不提供工具软件和授权文件。

重新构建尚未在整理目录中跑完整物理流程。硬件初始化数据（含DDR ROM txt、显示配置dat以及mem）必须保留。

软件回归：python pc_app/tests/test_combined_views.py。RTL回归：设置VIVADO_BIN后运行python scripts/run_tests.py。输出只写入build目录及脚本生成的检查回执，均应忽略Git提交。
